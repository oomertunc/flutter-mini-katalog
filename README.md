# Mini Katalog Uygulamasi

Flutter ile hazirlanan urun katalog demosu. Urunleri GridView ile listeler; arama, urun detayina gezinme ve basit sepet sayaci icerir.

## Gereksinimler
Flutter SDK ve Dart SDK 3.0+, Android Studio/VS Code ve Android emulator veya cihaz.

## Calistirma
1. `flutter pub get`
2. Emulatoru baslatin veya Android cihaz baglayin.
3. `flutter run`

Flutter surumunu `flutter --version` ile ogrenip teslim oncesi burada belirtin. Uygulama ornek urun verisiyle calisir.
